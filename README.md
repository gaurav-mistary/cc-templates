# Custom Cookiecutter Templates (`cc-templates`)

Welcome to your centralized Cookiecutter Templates repository! This repository is designed to be a **fork** (or a synced downstream clone) of the main `cc` engine.

## What happens here?
This repository is where you build your **Hybrid Templates**. 

Instead of maintaining a monolithic `cookiecutter.json` that tries to do everything, you create mixed templates using Git branches.

For example, if the upstream `cc` repository provides:
- A `traefik` branch (Base traefik setup)
- A `dockhand` branch (Base dockhand setup)

You can create a `traefik--secure` branch here to add Let's Encrypt, and then a `traefik--secure--dockhand` branch that merges all three technologies into one cohesive template!

## Workflow
1. **Sync Base Updates**: Fetch the latest updates from the upstream `cc` repository (e.g., when Python 3.13 drops, or Traefik is updated).
2. **Cascade**: Run `just cc cascade`. The automation will automatically merge those base updates down into all of your hybrid branches (`traefik--secure`, etc.).
3. **Resolve Conflicts**: If an automated merge fails due to conflicting files (like `docker-compose.yml`), you manually resolve it on that specific branch, commit, and resume.
4. **Publish**: Add your new hybrid template to the `registry.json` on the `main` branch so it can be generated by users via `just tc new <friendly-name>`.

## Example
If your `registry.json` looks like this:
```json
{
  "secure-dockhand": "traefik--secure--dockhand"
}
```
Any developer can generate that massive hybrid template effortlessly by running:
```bash
just tc new secure-dockhand
```
